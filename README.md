<details>
<summary><b>IntelliQ</b> · a personalized AI ecosystem across six client surfaces</summary>

<br>

| Decision | Why it is built that way |
|---|---|
| **Strict three-tier separation** | Clients are deliberately thin. No client contains business logic, and no client has a database connection, so a compromised surface cannot become a compromised system. |
| **Permissions fail closed** | Four tiers, from read-only to autonomous. Everything above read-only is off until explicitly granted, and an error *inside* a permission check is treated as a denial rather than an allowance. |
| **Encryption above the database** | AES-256-GCM applied in the application layer, so the key never lives in the same place as the ciphertext. |
| **Modular monolith, not premature microservices** | Each module owns exactly one repository file, and only that file writes SQL against its tables. The boundary is enforceable without paying for a network hop. |
| **Provider failover written by hand** | A router over OpenRouter walks a model chain and falls through on timeout, 429 or 5xx. One API key, no LangChain anywhere in the request path. |
| **Schema before code** | Third normal form, with a migration runner written from scratch instead of inherited from an ORM. |
| **Infrastructure I administer** | Docker on an Oracle Cloud Always Free instance, reached through a Cloudflare Tunnel, with a correlation ID on every request. |

<br>

`Node.js` `Express` `PostgreSQL` `Docker` `Oracle Cloud` `Cloudflare Tunnel`

</details>

<details>
<summary><b>Edgix</b> · an automated, pipelined AI trading bot with a human kill switch</summary>

<br>

| Decision | Why it is built that way |
|---|---|
| **Services never call each other** | Everything moves through an at-least-once event stream on Redpanda with a schema registry. There is no direct service-to-service call anywhere in the system, so any component can be restarted or replaced in isolation. |
| **The guardrails are the most tested code in the repo** | Position size is a function of *which source produced the signal*, with hard caps on top. The risk service can veto any decision, and that veto is not overridable at runtime. |
| **Execution is idempotent** | It rejects stale approvals, so a replayed or delayed event cannot open the same position twice. |
| **The listing scanner is isolated** | Its own deployment and its own network rules, feeding cold-start signals in from outside the trading-critical path. |
| **The sentiment engine emits a number, not prose** | A self-hosted fine-tuned model with retrieval over news, whose output is a bounded score in a known range rather than free text that downstream code has to trust. |
| **Paper and live are structurally separate** | Different topics, different schemas, different namespaces. Switching between them is not a config flag someone can flip by accident. |
| **Stopping is deliberate** | The kill switch is the single write path a human reaches for, and every use of it is recorded. |

<br>

`Python` `Redpanda` `PyTorch` `scikit-learn` `Docker` `Prometheus` `Grafana` `OpenTelemetry`

</details>
